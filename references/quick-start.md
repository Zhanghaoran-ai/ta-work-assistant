# 快速上手指南

本指南帮助你在5分钟内完成TA工作助手的配置和首次使用。

---

## 📋 前置条件

- 你的企业已经开通了飞书招聘
- 你有飞书开放平台的应用创建权限（或管理员协助）
- 你有招聘相关的角色权限（招聘专员、HRBP、面试官等）

---

## 🚀 三步快速开始

### 第一步：创建飞书自建应用（5分钟）

#### 1.1 进入开发者后台

访问 [飞书开放平台](https://open.feishu.cn/app)，点击「创建企业自建应用」

#### 1.2 填写应用信息

- 应用名称：TA工作助手（或你喜欢的名字）
- 应用描述：个人智能招聘工作台账
- 应用图标：随便选一个

#### 1.3 申请权限

进入「权限管理」，申请以下权限：

| 权限名称 | scope | 说明 |
|----------|-------|------|
| 获取投递信息 | `hire:application:readonly` | 读取简历投递数据 ✅ 必需 |
| 获取职位信息 | `hire:job:readonly` | 读取岗位信息 ✅ 必需 |
| 获取职位综合信息 | `hire:job.composite_info:readonly` | 岗位详情 ✅ 必需 |
| 获取招聘需求信息 | `hire:job_requirement:readonly` | 招聘需求 ⭐ 推荐 |
| 获取面试信息 | `hire:interview:readonly` | 面试安排 ✅ 必需 |
| 获取人才信息 | `hire:talent:readonly` | 候选人简历 ✅ 必需 |
| 获取用户基本信息 | `contact:user.base:readonly` | 获取当前用户ID ✅ 必需 |

> 申请后需要管理员审批，审批通过才能使用。

#### 1.4 获取凭证

进入「凭证与基础信息」，记录下：
- `App ID`：类似 `cli_xxxxxxxxxx`
- `App Secret`：点击「查看」获取

---

### 第二步：配置TA工作助手（2分钟）

#### 2.1 选择认证模式

| 模式 | 适合场景 | 推荐度 |
|------|----------|--------|
| **用户身份模式** | 个人待办，每个人用自己的权限 | ⭐⭐⭐⭐⭐ 推荐 |
| 应用身份模式 | 管理员视角，看全公司数据 | ⭐⭐ 特定场景 |

> 个人使用强烈推荐**用户身份模式**，安全，权限跟你本人一致。

#### 2.2 配置参数

你可以通过以下方式配置（选一种即可）：

**方式A：对话引导配置（最简单）**

直接跟TA工作助手说：
> "帮我配置一下，我的App ID是cli_xxx，App Secret是xxx"

然后按照引导完成授权即可。

**方式B：环境变量配置（适合部署）**

设置以下环境变量：
```bash
# 应用凭证
FEISHU_APP_ID=cli_xxxxxxxxxx
FEISHU_APP_SECRET=xxxxxxxxxx

# 认证模式：user（用户身份）或 tenant（应用身份）
AUTH_MODE=user

# 域名：feishu（国内）或 lark（国际）
FEISHU_DOMAIN=feishu
```

**方式C：配置文件**

创建 `config.yaml`：
```yaml
feishu:
  app_id: "cli_xxxxxxxxxx"
  app_secret: "xxxxxxxxxx"
  domain: "feishu"

auth:
  mode: "user"  # user 或 tenant

settings:
  timeout_warning_days: 3
  timeout_critical_days: 7
  cache_enabled: true
  data_storage_enabled: true
```

---

### 第三步：首次使用（1分钟）

#### 3.1 授权登录

配置完成后，TA工作助手会给你一个授权链接：
> 🔗 请点击链接授权飞书招聘访问权限：
> https://open.feishu.cn/open-apis/authen/v1/index?...

点击链接 → 飞书扫码 → 确认授权 → 完成！

#### 3.2 试试这些指令

授权成功后，试试问：

| 你可以问 | 会得到什么 |
|----------|------------|
| "今天有什么待办？" | 今日待办清单，按优先级排序，每条带链接 |
| "有哪些超时的任务？" | 超时任务清单，分级预警 |
| "帮我筛一下前端的简历" | 简历初筛分析和推荐 |
| "下午的面试帮我准备一下" | 面试准备包 |
| "这个月工作量怎么样" | 月度工作报表 |

## ⚙️ 常用配置说明

### 超时预警天数调整

默认：3天预警（黄），7天严重（红）

修改方式：
> "把超时预警改成2天预警，5天算严重超时"

### 优先级规则调整

默认优先级：急招 > 内推 > 即将超时 > 高匹配

你可以说：
> "我更看重内推，把内推的优先级调到最高"
> "急招和超时哪个更重要？我觉得超时更重要"

### 数据沉淀开关

默认开启，会把你的筛选标准、面试问题沉淀到个人多维表格。

关闭方式：
> "关掉数据沉淀功能"

## ❓ 常见问题

### Q1：提示"权限不足"怎么办？

**原因**：应用没有申请对应的scope，或者管理员还没审批。

**解决方法**：
1. 去飞书开放平台检查权限是否都申请了
2. 找管理员审批权限申请
3. 审批通过后重新授权一次

### Q2：为什么看不到某些岗位的简历？

**原因**：你本人在飞书招聘里没有这个岗位的权限。

**解决方法**：
- 找招聘管理员给你加对应岗位的权限
- 这是飞书招聘的权限控制，TA工作助手只能看你能看的数据

### Q3：数据多久更新一次？

- 待办列表：实时拉取，缓存5分钟
- 职位信息：缓存1小时
- 候选人信息：缓存30分钟

强制刷新可以说："刷新一下最新数据"

### Q4：我的数据安全吗？

**非常安全**：
- 所有API调用走HTTPS加密
- 你的token只在你的会话中使用
- 数据沉淀只存在你个人的多维表格里
- 遵循最小权限原则，只申请必要的权限
- 不会把你的数据分享给任何人

### Q5：可以给团队用吗？

可以，有两种方式：
1. **每个人自己配置**：每个人用自己的身份授权，看自己的数据（推荐）
2. **应用身份模式**：用应用身份，配置团队范围的权限，看团队数据（需要管理员）

### Q6：支持国际版Lark吗？

支持！配置时把 domain 改成 `lark` 即可：
```
FEISHU_DOMAIN=lark
```

## 📞 遇到问题怎么办？

1. **先看错误提示**：通常会告诉你是什么问题、怎么解决
2. **检查权限**：90%的问题都是权限没开对
3. **重新授权**：token过期的话重新授权一下就行
4. **查看日志**：开启调试模式，看详细的API调用日志
