# TA 工作助手

> 基于飞书招聘开放平台API的个人智能工作台账与任务管理工具

[![version](https://img.shields.io/badge/version-v2.1.0-blue)](https://github.com/Zhanghaoran-ai/ta-work-assistant)
[![license](https://img.shields.io/badge/license-MIT-green)](LICENSE)

## 📋 项目介绍

TA工作助手是面向招聘专员/HRBP的**个人智能工作台账**，基于飞书招聘开放平台API，从**待办任务视角**出发，帮你梳理任务优先级、时间分布和精力分配建议。

**核心定位**：不是数据报表工具，而是你的**个人任务管家**——告诉你"今天该做什么、先做什么、怎么做最高效"，并且每条任务都带直达链接，看完就能点进去处理。

## ✨ 核心功能

### 1. 智能待办清单
- 待办任务汇总（待评估简历、待面试、待写评估）
- 优先级智能排序（急招 > 内推 > 即将超时 > 高匹配）
- 超时预警（黄/红两级预警）
- 时间与精力分配建议

### 2. 定时推送与主动提醒 ⭐ 新增
- **早间每日看板**：工作日早上9点推送当日工作安排
- **午间提醒**：下午面试提醒 + 上午待办回顾
- **下班前收尾**：今日完成情况 + 未完成提醒
- **周度汇总**：本周工作汇总 + 下周待办预览
- **事件驱动提醒**：新急招简历、面试前提醒、超时预警等

### 3. 工作量与效率分析
- 工作量概览与分布统计
- 效率分析与趋势对比
- 候选人画像统计

### 4. 简历处理辅助
- 简历快速摘要
- 多候选人横向对比
- 智能初筛（匹配度评分 + 结论）

### 5. 面试支持
- 面试准备包（背景摘要 + 关注点 + 提问方向）
- 面试纪要整理
- 面试题库推荐

### 6. 流程追踪
- 候选人全流程追踪
- 时效分析与瓶颈识别
- 岗位招聘进度

### 7. 数据沉淀
- 个人面试经验库（飞书多维表格）
- 评估标准沉淀（越用越懂你的偏好）

## 🚀 快速开始

### 前置条件
- 企业已开通飞书招聘（Lark Hire）
- 拥有飞书开放平台自建应用权限
- 应用已开通招聘相关API权限

### 三步快速上手

1. **创建飞书自建应用**
   - 登录飞书开放平台，创建自建应用
   - 开通招聘相关权限（`hire:application:readonly` 等）
   - 获取 App ID 和 App Secret

2. **配置TA工作助手**
   - 配置 App ID / App Secret
   - 选择认证模式（推荐用户身份模式）
   - 配置超时预警、优先级规则等参数

3. **开始使用**
   - 说"帮我看看今天有什么待办"即可查询
   - 说"帮我设置每天早上9点推送"开启定时推送

详细配置说明请参考：[快速上手指南](references/quick-start.md)

## 🔧 配置说明

### 必需配置项

| 配置项 | 说明 |
|--------|------|
| `app_id` | 飞书自建应用的App ID |
| `app_secret` | 飞书自建应用的App Secret |
| `auth_mode` | 认证模式：`user`（用户身份）/ `tenant`（应用身份） |

### 常用可选配置项

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `timeout_warning_days` | 简历评估超时预警天数（黄） | 3 |
| `timeout_critical_days` | 简历评估严重超天天数（红） | 7 |
| `push_enabled` | 是否启用定时推送功能 | false |
| `push_morning_time` | 早间推送时间 | 09:00 |
| `event_reminder_enabled` | 是否启用事件驱动提醒 | false |

完整配置项请参考 [SKILL.md](SKILL.md)。

## 🔌 数据来源

基于**飞书开放平台招聘API（hire/v1）**实现，支持所有使用飞书招聘的企业。

主要接口模块：
- 投递管理 `/hire/v1/applications`
- 职位管理 `/hire/v1/jobs`
- 人才管理 `/hire/v1/talents`
- 面试管理 `/hire/v1/interviews`
- 招聘需求 `/hire/v1/job_requirements`

详细接口说明请参考：[API接口参考](references/api-reference.md)

## ⚠️ 能力边界

### ✅ 可以做到
- 个人维度的工作量统计和分析
- 待办提醒和超时预警
- 简历摘要、对比、初筛辅助
- 面试准备和纪要整理
- 定时推送和事件驱动提醒
- 个人数据沉淀和经验积累
- 支持所有使用飞书招聘的企业

### ❌ 做不到
- 直接在飞书招聘系统中执行写操作（改状态、推进流程）
- 获取其他HR或团队的招聘数据（用户身份模式下）
- 获取全公司级别的招聘统计
- 自动执行需要人工确认的操作

> **原则**：AI辅助决策，人工确认执行
